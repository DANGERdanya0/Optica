# Общая информация о сайте

## Основная идея чайта и его цели

**Тема сайта:**Интернет магазин оптики
**Цель:**Создание полностью функционального многостраничного сайта для интернет магазина.
**Название:** DIVOptica

## Технологии для разработки

**Языки для разметки:**HTML, CSS
**Языки для back-end:**JavaScript,TypeScript
**Библиотеки:**TailWind
**Хранение данных:**Массивы JSON

## Основная задача

Создать адаптивное WEB-приложение, через которое люди могут купить очки\линзы, заказать сервисное обслуживание, обратиться к окулисту и т.д.
