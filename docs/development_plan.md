# План поэтапной разработки проекта "DIVOptica"

Этот документ разделяет весь процесс разработки на логические этапы для систематического создания функционала.

---

### Этап 1: Основа и Главная страница

**Цель:** Заложить архитектурную основу сайта и реализовать главную, "приветственную" страницу.

**Задачи:**
- Настройка базовой структуры проекта.
- Создание статических, сквозных элементов сайта:
  - **Шапка (Header)** и **Подвал (Footer)**. Подробнее в файле: [`siteElement.md`](./siteElement.md)
- Реализация главной страницы (`Main`) со всеми блоками:
  - Слайдер акций.
  - Блок "Товары недели".
  - Баннеры "Выберите свою пару" и "О нас".
  - Блок "Проверьте зрение".
- Вся структура страниц и детальное описание блоков главной страницы находятся в файле: [`structure.md`](./structure.md)

---

### Этап 2: Каталог и Товары

**Цель:** Реализовать функционал для просмотра и фильтрации товаров.

**Задачи:**
- Определение структуры данных для товаров. См. [`Products.md`](./Products.md)
- Создание компонента **"Карточка товара"**. Описание в файле: [`Products.md`](./Products.md)
- Разработка страницы **"Каталог" (`Shop`)**:
  - Модальное окно выбора категорий.
  - Сайдбар с поиском и фильтрами (цена, бренд, цвет и т.д.).
  - Сетка для отображения отфильтрованных товаров.
- Детальное описание страницы каталога находится в файле: [`structure.md`](./structure.md)

---

### Этап 3: Пользовательские сценарии

**Цель:** Реализовать функции, связанные с взаимодействием пользователя: регистрация, авторизация и управление личными данными.

**Задачи:**
- Реализация модального окна **авторизации и регистрации**. Подробное описание в файле: [`auth.md`](./auth.md)
- Создание **личного кабинета пользователя (`User`)** в виде модального окна со вкладками:
  - Редактирование данных.
  - История заказов.
  - Корзина (детальное описание в [`cart.md`](./cart.md)) и избранное.
- Общее описание личного кабинета: [`user_profile.md`](./user_profile.md)

---

### Этап 4: Информационные страницы

**Цель:** Создать статические страницы, предоставляющие дополнительную информацию для клиентов.

**Задачи:**
- **О нашей оптике (`Info`):** Страница с историей компании и отзывами.
- **Здоровье глаз (`Healty`):** Страница с тестом зрения и записью к врачу.
- **Сервисное обслуживание (`Service`):** Описание услуг по ремонту.
- **Наши филиалы (`Branchs`):** Карта и список филиалов.
- **Поддержка (`Support`):** FAQ и форма обратной связи.
- Структура всех информационных страниц описана в файле: [`structure.md`](./structure.md)

---

### Этап 5: Администрирование

**Цель:** Создать инструменты для управления контентом и данными сайта.

**Задачи:**
- Реализация **панели администратора (`Admin`)** в виде модального окна со вкладками:
  - Управление товарами.
  - Управление заказами.
  - Управление пользователями и их ролями.
  - Управление контентом (слайдер, акции).
- Детальное описание админ-панели: [`admin_panel.md`](./admin_panel.md)
