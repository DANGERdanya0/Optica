# Админ панель

Доступ к админ-панели должен быть только у пользователей с ролью "администратор". Панель представляет собой модальное окно с несколькими вкладками для управления сайтом.

## 1. Управление товарами
- **Просмотр:** Таблица со всеми товарами, с возможностью поиска и фильтрации.
- **Добавление:** Форма для добавления нового товара со всеми полями (название, категория, цена, характеристики и т.д.).
- **Редактирование:** Возможность изменить любой параметр существующего товара.
- **Удаление:** Возможность удалить товар.

## 2. Управление заказами
- **Список заказов:** Таблица всех заказов с их статусами (новый, в обработке, доставлен, отменен).
- **Детали заказа:** Просмотр подробной информации о конкретном заказе (состав, данные покупателя, адрес доставки).
- **Смена статуса:** Возможность изменять статус заказа.

## 3. Управление пользователями
- **Список пользователей:** Таблица со всеми зарегистрированными пользователями.
- **Редактирование роли:** Возможность назначать или снимать роль администратора.
- **Блокировка:** Временная или постоянная блокировка пользователя.

## 4. Управление контентом
- **Акции и слайдер:** Интерфейс для добавления/изменения/удаления слайдов на главной странице.
- **Редактирование страниц:** Возможность редактировать текстовые блоки на информационных страницах (например, "О нас").
