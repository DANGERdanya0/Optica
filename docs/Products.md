# Структура товаров

## Общая структура
 - id
 - Категория
 - подкатегория
 - Бренд
 - Название
 - Описание
 - Характеристики(Для каждой категории свои)
 - Количество
 - Цена
 - Скидка (в процентах)
 - Изображения (массив ссылок на фото)

## Шаблон JSON

Для каждой категории должен быть отдельный файл JSON в директории @products/category.json.

Пример для `products/glasses.json`:
```json
[
  {
    "id": "gl001",
    "category": "Очки",
    "subcategory": "Солнцезащитные",
    "brand": "Ray-Ban",
    "name": "Aviator Classic",
    "description": "Классические очки-авиаторы, которые никогда не выходят из моды.",
    "characteristics": {
      "материал оправы": "металл",
      "цвет линз": "зеленый",
      "UV-защита": "100%"
    },
    "quantity": 15,
    "price": 15000,
    "discount": 10,
    "images": [
      "@media/products/gl001-1.jpg",
      "@media/products/gl001-2.jpg"
    ]
  }
]
```

# Карточка товара

Карточка товара — это основной элемент для представления продукта в каталоге и на главной странице.

## Структура и вид
- **Контейнер:** Блок с закругленными углами и тенью при наведении.
- **Изображение:** Занимает верхнюю часть карточки. При наведении на карточку изображение плавно сменяется на второе из массива `images`, если оно есть.
- **Название:** Крупный шрифт, расположен под изображением.
- **Цена:** Расположена под названием. Если есть скидка (`discount > 0`), старая цена отображается перечеркнутой, а рядом — новая, рассчитанная цена (`price * (1 - discount / 100)`). Новая цена выделена цветом.
- **Кнопка "В корзину":** Расположена внизу карточки. При наведении меняет цвет.

## Взаимодействие
- **Клик по карточке:** Переход на страницу с подробным описанием товара.
- **Наведение:** Появляется легкая тень, второе изображение (если есть), и может появляться дополнительная иконка "Добавить в избранное".
