# Общие элементы сайта (Header,footer и т.д.)

## общие элементы

На сайте будут реализованы **Header** и **Footer**, они будут одинаковые для всего сайта, они будут статичными.

## Структура элементов

### Header

**Вид:** Хедер должен иметь отступ от краев по **_20px_** с каждой стороны иметь другой цвет и иметь закругленные рамки.
**Заполнение:** В хеадере по центру должен быть логотип\названия компании в нашем случае **DIVOptica**, слева от него должны находиться кнопк:**Каталог**(Shop),**Здоровье**(health). А справа от лого должны быть кнопки:**О нас**(Info), **Сервис**(Service). При нажатии на которые они будут переходить на странички закрепленные за ними, в своей очереди при нажатии на лого будет осуществляться переход на главную страницу. В лувом углу должна быть иконка стрелочка вниз, при нажатии на ней из левого края хеадера выезжает меню где находяться кнопки: **Филиалы** и **Поддержка**. В правом углу хеадера должна быть иконка аккаунта при нажатии на нее должно вылезать модальное окно с Авторизацией\регистрацией пользователя(будет разработана чуть позже).

### Footer

Стандартный подвал сайта.
