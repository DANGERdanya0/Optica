# Структура страниц сайта

## Краткое описание

На сайте должно быть удобные и функциональные страницы например главная и админ панель, так же доступ к некоторым страницам будт иметь определенные роли, то есть админ будет иметь доступ к админ панели(ее чтруктуру опишу позже), а авторизованный пользователь будет иметь доступ только к своему личному кабинету и к заказу товаров.

## Страницы

**Main:** Главная
**Info:** О нашей оптике
**health:** Здоровье глаз
**Shop:** Каталог
**Service:** Сервисное обслуживание
**branches:** Наши филиалы
**Support:** Поддержка
**User:** Личный кабинет(Всплывающее модальное окно, структура будет расписана в отдельном файле `user_profile.md`)
**Admin:** Админ панель(Всплывающее модальное окно, структура будет расписана в отдельном файле `admin_panel.md`)

### Примечание

Полная информация по блокам будет описана ниже

## Главная страница(main)

Эта страница будет приветственной она должна быть современно оформлена, а так же на ней должна быть краткая информация о оптике, акции и предложения, а так же ссылки на все страницы с их кратким описанием.

### Структура страницы

#### Слайдер

**Взаимодействие:** Слайдер должен автоматически перелистываться каждие _10 секунд_, так же при нажатии на слайд пользователь должен проваливаться на товар с акцией или каталог колекции которая была указана на слайде, еще у слайдера должны быть две кнопки для принудительного переключения между слайдами.
**Анимация:** Слайдер должен иметь анимацию затухания слайда затем проявления нового
**Заполнение:** Пока создай заглушки в директории @media/slider, вскоре они будут заменены на окончательные варианты.
**Вид:** слайдер должен занимать 80% ширины окна, но если сайт открыт в большом формате то не слайдер должен быть не более 750px, формат слайда 21:9.

#### Товары недели

**Вид:** Ниже слайдера должен быть заголовок, еще ниже топ 5 товаров нашего магазина в виде карусели карточек товара.
**Взаимодействие:** пользователь при наведении на карточкуу товара может увидеть доп информацию по товару, а так же при нажатии перейти на страничку товара.

##### Примечание

Понятие **"карточка товара"** будет внесено в файле @docs/products.md!

### Выберите свою пару

**Заполнение:** Справа изображение очков, слева привлекающий баннер **_выбери свою пару прямо сейчас_**
**Взаимодействие:** При нажатии на кнопку **_выбери свою прау прямо сейчас_** происходит переход на страницу **Shop**

### О нас

**Заполнение:** Справа фотография плавно переливающаяся в прозрачный цвет, сдева краткий текст о компании и кнопка для перехода к странице **Info**.
**Анимация:** При наведении на блок картинка должна стать светлее, при не актвном блоке он должен быть затемнем.

### Проверьте зрение

**Заполнение:** сначала должна быть анкета ведущего специалиста и кнопка для перезода на страничку **health**.
**Взаимодействие:** Пользователь может нажать на анкету и посмотреть расширеную анкету специалиста, так же при нажатии кнопки проверить здоровье должен быть переход на страницу **health**.
**Анимации:** При наведении на кнопку она должна поменять свой цвет и блок должен стать ярче

## О нашей оптике(Info)

На данной странице будет 3 блоков, страница будет больше в текстовом формате как газета.

### Общая инфа

**Заполнение:** Большой слоган **_"DIVOptica - Зрение без компромиссов!"_** на фоновом изображении магазина оптики. Чуть ниже надпись **_"Работаем 15 лет"_**

### Блок о нас

**Вид:** выделеный фрейм с текстом о компании.
**Наполнение:** Заголовок **_О нашей компании_**, текст(Сгенерируй сам).

### Блок с отзывами

**Вид:** Блок с заголовком и слайдером с отзывами.
**Наполнение:** Оценка от 0 до 5 звезд(в среднем 5 звезд), имя, приобретенный товар, отзыв

## Каталог(Shop)

Страница каталога товаров, где пользователь может просматривать, фильтровать и искать товары.

### Категории

При переходе на страницу каталога, появляется модальное окно, предлагающее выбрать основную категорию товара (Очки, Аксессуары, Средства для ухода). Выбор категории фильтрует отображаемые товары.

### СайдБар

Этот блок будет выступать в качестве панели фильтров для уточнения поиска товаров. Он должен быть зафиксирован слева.

#### Поиск

Интерактивная строка поиска вверху сайдбара для поиска товаров по названию или бренду в реальном времени.

#### Фильтры

Под строкой поиска располагаются аккордеоны с фильтрами:

- **Категория товара:** Радиокнопки для выбора основной категории.
- **Подкатегория товара:** Чекбоксы для выбора одной или нескольких подкатегорий.
- **Бренд:** Чекбоксы с брендами, доступными в выбранной категории.
- **Цвет:** Палитра цветов или чекбоксы для выбора цвета оправы/аксессуара.
- **Цена:** Ползунок для выбора диапазона цен "от" и "до".

### Каталог товаров

Основная часть страницы, где отображаются товары в виде сетки.

#### Карточки товара

- Фотография товара (плавно меняются при наведении или каждые 10 секунд).
- Название товара.
- Цена (старая цена перечеркнута, если есть скидка).
- Кнопка **"Добавить в корзину"**.

При нажатии на карточку товара происходит переход на отдельную страницу этого товара с подробным описанием.

## Здоровье глаз(health)

Страница, посвященная здоровью глаз и услугам окулиста.

### Структура страницы

1. **Интерактивный тест:** Простой онлайн-тест для предварительной проверки зрения (например, на астигматизм, дальтонизм). С обязательным примечанием, что тест не заменяет визит к врачу.
2. **Наши специалисты:** Блок с карточками ведущих врачей-окулистов. Каждая карточка содержит фото, ФИО, специализацию и стаж. При клике открывается подробная анкета.
3. **Запись на прием:** Форма для онлайн-записи к специалисту, с выбором врача, даты и времени.

## Сервисное обслуживание(Service)

Страница с информацией о предоставляемых услугах по ремонту и обслуживанию очков.

### Структура страницы

1. **Перечень услуг:** Список услуг с описанием и ценами (например, замена линз, ремонт оправы, ультразвуковая чистка).
2. **Как это работает:** Пошаговая инструкция (принесите очки -> мы проведем диагностику -> согласуем стоимость -> выполним работу).
3. **Форма заявки:** Форма для оставления заявки на сервис, где можно описать проблему и прикрепить фото.

## Наши филиалы(branches)

Страница с информацией о местонахождении физических магазинов.

### Структура страницы

1. **Интерактивная карта:** Карта (например, Яндекс.Карты или Google Maps) с отмеченными на ней филиалами.
2. **Список филиалов:** Под картой или сбоку от нее — список адресов. Каждый элемент списка содержит адрес, телефон, часы работы и фото магазина.

## Поддержка(Support)

Страница для связи с поддержкой и получения помощи.

### Структура страницы

1. **Часто задаваемые вопросы (FAQ):** Секция с аккордеоном, где собраны ответы на популярные вопросы (о доставке, оплате, возврате и т.д.).
2. **Форма обратной связи:** Форма для отправки вопроса в службу поддержки.
3. **Контакты:** Указание телефона горячей линии, email и ссылок на социальные сети.
