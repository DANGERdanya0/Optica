# Авторизация и Регистрация

Процесс аутентификации пользователя происходит в модальном окне, которое появляется при нажатии на иконку аккаунта в шапке сайта.

## Структура модального окна

Окно имеет две основные формы: для входа и для регистрации, между которыми можно переключаться.

### 1. Форма Авторизации (вид по умолчанию)

**Заголовок:** "Вход в личный кабинет"

**Поля:**
- **Email:** Поле для ввода электронной почты.
- **Пароль:** Поле для ввода пароля.

**Элементы управления:**
- **Кнопка "Войти":** При нажатии происходит попытка аутентификации. В случае успеха окно закрывается, и иконка в шапке меняется (например, на инициалы пользователя). В случае неудачи под полями появляется сообщение об ошибке ("Неверный email или пароль").
- **Ссылка "Забыли пароль?":** Открывает форму восстановления пароля.
- **Ссылка "Зарегистрироваться":** Переключает модальное окно на форму регистрации.

### 2. Форма Регистрации

**Заголовок:** "Создание аккаунта"

**Поля:**
- **Имя:** Поле для ввода имени пользователя.
- **Email:** Поле для ввода электронной почты.
- **Пароль:** Поле для ввода пароля. Должны быть требования к сложности (например, минимум 8 символов, одна буква, одна цифра).
- **Повторите пароль:** Поле для подтверждения пароля.

**Элементы управления:**
- **Кнопка "Зарегистрироваться":** При нажатии происходит валидация данных (совпадение паролей, корректность email). Если email уже существует, выводится ошибка. При успехе пользователь автоматически авторизуется, окно закрывается.
- **Ссылка "Уже есть аккаунт? Войти":** Возвращает на форму авторизации.

### 3. Восстановление пароля

**Заголовок:** "Восстановление доступа"

**Поля:**
- **Email:** Поле для ввода email, на который зарегистрирован аккаунт.

**Элементы управления:**
- **Кнопка "Отправить":** После нажатия появляется сообщение о том, что "инструкции по восстановлению пароля отправлены на указанную почту".
