# Личный кабинет пользователя

Личный кабинет представляет собой модальное окно, доступное авторизованным пользователям после клика на иконку профиля в шапке сайта.

## 1. Вкладка "Мои данные"
- **Персональная информация:** Поля для просмотра и редактирования имени, фамилии и контактного телефона.
- **Смена пароля:** Форма для смены текущего пароля.

## 2. Вкладка "История заказов"
- **Список заказов:** Отображение всех совершенных пользователем заказов.
- **Детализация:** Каждый заказ можно развернуть, чтобы увидеть список товаров, дату и сумму.
- **Статус:** Отображение текущего статуса заказа (например, "В пути", "Доставлен").

## 3. Вкладка "Корзина"

Вкладка отображает товары, добавленные пользователем для покупки. Она позволяет управлять количеством товаров, сравнивать их и переходить к оформлению заказа.

**Подробное описание структуры и функциональности корзины находится в отдельном документе: [`cart.md`](./cart.md).**

## 4. Вкладка "Избранное"
- **Список желаний:** Отображение товаров, которые пользователь добавил в "избранное".
- **Быстрые действия:** Возможность переместить товар из избранного в корзину или удалить его из списка.
