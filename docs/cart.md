# Корзина покупок

Корзина является ключевым элементом процесса покупки. Она реализована в виде вкладки в модальном окне личного кабинета.

## 1. Доступ и Общий вид
- **Доступ:** Пользователь попадает в корзину, нажав на иконку профиля в шапке сайта и выбрав соответствующую вкладку.
- **Заголовок:** Вкладка имеет заголовок "Корзина", рядом с которым в скобках отображается актуальное количество товаров (например, "Корзина (3)").
- **Состояние:** Корзина имеет два состояния: с товарами и пустое.

## 2. Структура корзины с товарами

Если в корзине есть товары, интерфейс делится на три основных блока: список товаров, блок с итоговой суммой и блок действий.

### Блок 1: Список товаров
Это прокручиваемая область, где каждый товар представлен отдельной строкой.

**Структура строки товара:**
- **Чекбокс:** Для выбора товара для сравнения.
- **Изображение:** Небольшое фото товара.
- **Название и Бренд:** Название товара является ссылкой на его страницу. Под названием указан бренд.
- **Количество:** Интерактивный счетчик (`-` / `1` / `+`) для изменения количества единиц товара.
- **Цена за единицу:** Стоимость одной единицы товара.
- **Итоговая цена:** Сумма за товар в строке (цена * количество).
- **Кнопка "Удалить":** Иконка для удаления товара из корзины.

### Блок 2: Итоговая сумма
Этот блок находится под списком товаров и содержит расчет стоимости:
- **Сумма товаров:** Общая стоимость всех товаров без учета скидок.
- **Скидка:** Общая сумма скидки (если применимо).
- **Итого:** Финальная сумма к оплате.

### Блок 3: Блок действий
- **Кнопка "Сравнить выбранные":** Становится активной, если выбрано 2 или более товара с помощью чекбоксов. Открывает модальное окно сравнения.
- **Кнопка "Оформить заказ":** Основная кнопка, ведущая на страницу/процесс оформления заказа.

## 3. Пустая корзина
Если пользователь не добавил ни одного товара, на вкладке отображается:
- **Текст:** "Ваша корзина пуста".
- **Изображение:** Тематическая иконка или изображение пустой тележки.
- **Кнопка "Перейти в каталог":** Яркая кнопка, призывающая начать покупки.

## 4. Структура данных (JSON)

Корзину можно хранить в `localStorage` браузера или в базе данных на сервере. Пример структуры:
```json
{
  "userId": "user123",
  "items": [
    {
      "productId": "gl001",
      "quantity": 1,
      "price": 15000,
      "discount": 10
    },
    {
      "productId": "ac002",
      "quantity": 2,
      "price": 2500,
      "discount": 0
    }
  ],
  "lastUpdated": "2026-03-03T14:25:00Z"
}
```
